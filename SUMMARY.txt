🚀 PRÓXIMOS PASOS PARA DESPLIEGUE

1. Obtener URL del Backend (ejemplo: https://api.vichisboh.com)

2. Elegir Plataforma de Hosting

   A) VERCEL (Recomendado para React/Vite):
      • npm install -g vercel
      • vercel login
      • vercel --prod
      • Configurar VITE_API_URL en dashboard
      
   B) NETLIFY:
      • npm install -g netlify-cli
      • netlify login
      • netlify deploy --prod --dir=dist
      • Configurar VITE_API_URL en Site Settings
      
   C) VPS/Servidor Propio:
      • npm run build (ya hecho ✓)
      • Copiar contenido de dist/ a raíz web
      • Configurar .env.production con tu API URL

3. Configurar Variable de Entorno

   En tu plataforma de hosting:
   VITE_API_URL = https://tu-backend-url.com

4. Verificar Post-Deploy

   En DevTools (F12):
   console.log(import.meta.env.VITE_API_URL)
   → Debe mostrar tu URL, no localhost
